# Отложенные задачи

## Напомнить владельцу проекта
- [ ] **Подключить Upstash Redis (сохранение партий на Render).** Без этого бесплатный Render при «сне»/перезапуске стирает комнаты и партии.
  Что нужно: зарегистрироваться на https://upstash.com → Create Database (Redis) → скопировать `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`
  → Render: сервис → Environment → добавить две переменные → Save. Код уже готов (версия 3.7), подробности в `README.md`, раздел «Сохранение партий».
  Напоминать: после второй волны обновлений и перед каждой «серьёзной» партией с друзьями.
