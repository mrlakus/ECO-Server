# Версии и откат

Каждая правка — отдельный «снимок» (коммит) в git; главные версии помечены тегами `v01…`, `v02…` и т.д.
Ничего не удаляется: можно вернуться к любой версии и потом снова вперёд.

## Посмотреть список версий
```bash
git tag -n
```

## Временно запустить старую версию (посмотреть, как было)
```bash
git checkout v09-dev-rezhim
npm install
npm run dev
```
Вернуться к самой новой:
```bash
git checkout claude/mobile-code-optimization-0m02dg
git pull
```

## Откатить последнюю правку (безопасно, история сохраняется)
```bash
git revert --no-edit HEAD
```
Это создаст новый снимок, который отменяет предыдущий. Если правок несколько — укажите нужный: `git revert --no-edit <код_коммита>`
(коды видны в `git log --oneline`).

## Вернуть проект целиком к версии и продолжить с неё
```bash
git checkout -b ot-starogo v09-dev-rezhim
```
Это создаст новую ветку `ot-starogo` с состоянием версии v09. Основная ветка при этом не меняется.

## Если что-то пошло не так
Сохранить текущую работу под тегом можно в любой момент: `git tag -a моя-метка -m "описание"`.
