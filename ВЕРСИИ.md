# Версии и откат

Каждая правка — отдельный «снимок» (коммит) в git. Ничего не удаляется: можно вернуться к любой версии
и потом снова вперёд. У каждой версии есть короткий код (хеш) — по нему и переключаемся.

## Временно запустить старую версию (посмотреть, как было)
```bash
git checkout 58957fa
npm install
npm run dev
```
(`58957fa` — пример, подставьте код нужной версии из таблицы.) Вернуться к самой новой:
```bash
git checkout claude/mobile-code-optimization-0m02dg
git pull
```

## Откатить последнюю правку (безопасно, история сохраняется)
```bash
git revert --no-edit HEAD
```
Создаётся новый снимок, который отменяет предыдущий. Отменить конкретную правку: `git revert --no-edit <код>`.

## Начать новую ветку от старой версии
```bash
git checkout -b ot-starogo 58957fa
```
Появится ветка `ot-starogo` с состоянием той версии; основная ветка не меняется.
