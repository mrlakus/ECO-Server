# Три сестры — онлайн

Браузерная версия настольной игры «Три сестры» (Бенджамин Пинчбэк, Мэтью Д. Риддл; русское издание — Crowd Games)
для 2–4 игроков. Обычная версия, без дополнения «Погода» и без одиночного режима.
Графика — собственная схематичная (оригинальные иллюстрации не используются).

## Запуск

```bash
npm install
npm start          # соберёт клиент и запустит сервер на http://localhost:3000
PORT=8080 npm start
npm test           # тесты движка, включая 60 полных партий случайными ходами
npm run dev        # режим разработки: сам перезапускает сервер и пересобирает страницу при изменении файлов (удобно после git pull)
```

Создайте комнату, отправьте друзьям код или ссылку `?room=КОД`, хозяин нажимает «Начать игру».
Ход делается в два этапа: сначала вы всё выбираете (выбранное видно на листе синим), потом нажимаете «Подтвердить ход»; «Отменить шаг» и «Заново» откатывают выбор до отправки.
Не с кем играть — нажмите «🤖 Добавить бота» в комнате: бот ходит сам (оценка позиции + просчёт хода при выборе кубика).
Переподключение после обрыва связи — автоматическое (токен хранится в браузере).
Кнопка «🏳 Закончить игру» в шапке предлагает всем закончить партию: боты всегда согласны, люди отвечают в окне; если согласны все — выход в главное меню, иначе игра продолжается. Всё пишется в журнал.

## Устройство

- `src/shared/data.ts` — все числа планшета (грядки, тыквенное кольцо, многолетники, пасека, сад, сарай, рынок).
- `src/shared/engine.ts` — движок правил; состояние — обычный JSON, сервер проверяет каждый ход.
- `src/shared/bot.ts` — бот-соперник.
- `src/server/index.ts` — HTTP (статика) + WebSocket, комнаты.
- `src/client/main.ts` — интерфейс: две вкладки — «Поле» (общее: кубики, рынок, игроки, журнал) и «Планшет» (личный лист целиком на одном экране, нажимаются прямо клетки); собирается esbuild.

## Допущения, где правила неоднозначны

- Предмет сарая действует с момента подготовки (в т.ч. тачка срабатывает и на действии, которое её подготовило);
  исключение — «красивые этикетки» по прямому указанию правил.
- Компост, потраченный на сдвиг кубика, сохраняется на весь ход (для обоих действий «Посадка или полив»);
  бонус ириса действует на каждое действие отдельно.
- Кнопка «Пропустить» позволяет отказаться от действия (защита от зависания), хотя по правилам действие обязательно.

## Размещение на Render (бесплатно)

1. Зарегистрируйтесь на https://render.com (удобно через GitHub) и разрешите доступ к репозиторию.
2. **New + → Blueprint** → выберите репозиторий → Render прочитает `render.yaml` → **Apply**.
   (Либо вручную: **New + → Web Service**, Build: `npm install --include=dev && npm run build:prod`, Start: `npm run start:prod`, Health check: `/healthz`, план Free.)
3. Через пару минут появится адрес вида `https://tri-sestry.onrender.com` — отправьте его другу.

Особенности бесплатного тарифа: после ~15 минут без активности сервис засыпает, первый заход после этого грузится около минуты;
комнаты хранятся в памяти, поэтому после перезапуска/«сна» они сбрасываются. В `render.yaml` указана ветка `claude/mobile-code-optimization-0m02dg` — замените на нужную.
Проверка собранной версии локально: `npm run build:prod && npm run start:prod`.

## Журнал сервера
Сервер пишет события в стандартный вывод (на Render: сервис → **Logs**): создание комнат, вход/выход/отключение игроков (по именам, без IP),
старт и итог партии со счётом, досрочное окончание, закрытие комнат и раз в 5 минут сводка «сколько комнат и людей онлайн».

## Музыка меню
В главном меню и комнате ожидания играет спокойная деревенская мелодия (синтезируется в браузере, файлов нет). Кнопка 🎵/🔇 и ползунок громкости — в правом верхнем углу;
настройки запоминаются. Звук стартует после первого касания (так требуют браузеры), в самой игре музыки нет.

## Открытые комнаты и пароль
В меню виден список комнат (хозяин, сколько игроков, 🔒 если есть пароль), обновляется сам. Нажмите «Войти» — для комнаты с паролем появится окно ввода.
При создании комнаты можно задать пароль (необязательно); хранится только его хеш, подбор ограничен (6 попыток в минуту). Вернуться в свою комнату после обрыва связи можно без пароля.

## Чат и реакции
Кнопка 💬 в углу (в комнате ожидания и в игре): сообщения, быстрые фразы и смайлы-реакции (они всплывают на экране у всех). Хранятся последние 100 сообщений комнаты,
вернувшийся игрок получает историю. Есть защита от спама (не чаще раза в 0,4 с и 12 сообщений за 20 с), HTML вычищается.

## Сохранение партий (переживают перезапуск)
Комнаты и партии сохраняются после каждого действия (с задержкой ~1,5 с) и при остановке сервера, восстанавливаются при запуске; игроки возвращаются по ссылке автоматически. Хранятся 3 дня.
- **Локально:** папка `data/` (можно изменить: `DATA_DIR=/путь`), включено само.
- **Render (бесплатный тариф стирает файлы при перезапуске):** подключите бесплатную базу Upstash Redis:
  1. Зарегистрируйтесь на https://upstash.com → **Create Database** (Redis, тип Regional, любой регион).
  2. На странице базы найдите блок **REST API** и скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
  3. В Render: сервис → **Environment** → добавьте эти две переменные → **Save** (сервис перезапустится).
  В журнале появится «сохранение партий: Upstash Redis». Без этих переменных на Render сохранение выключено (в журнале так и написано).
- Выключить принудительно: `SAVE=off`.

## Звуки и анимации
Звуки (синтезатор): бросок кубиков в начале раунда, посадка, полив, урожай, подтверждение хода; чужие действия звучат тише. Анимации: кубики «выкатываются», новые закрашенные клетки вспыхивают,
панель внизу пульсирует, когда ваш ход, урожай соперника сопровождается «✨». Звуки игры выключаются в ⚙; при включённом «уменьшении анимации» в системе анимации отключаются.

## Установка как приложения (PWA)
- **Android/Chrome и компьютер:** в меню появляется кнопка «📲 Установить как приложение» (или значок установки в адресной строке).
- **iPhone:** Safari → «Поделиться» → «На экран “Домой”» (в меню есть кнопка с пошаговой подсказкой).
Приложение открывается в полный экран со своей иконкой. Сервис-воркер хранит оболочку сайта и всегда сначала берёт свежую версию из сети, так что после обновления на сервере устаревшего кода не будет.
Играть без интернета нельзя (это онлайн-игра), но страница открывается и сама переподключается к серверу.
